#  Physics Engine

## 📝 More information

This project was made with Unity. We were 3 and had to implement a 3D Physics Engine that could handle collisions detection and collision responses.

## ⌨️ Controls

|    Key   |     Action    |
|     :---:     |     :---:     |
|    LEFT MOUSE BUTTON   |       Left flipper             |
|    RIGHT MOUSE BUTTON   |       Right flipper             |
|    SPACE   |       Launch ball           |
|    A   |       Spawn new ball            |
